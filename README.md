# GST Finder — Full rebuild starter

## Run
python -m pip install -r requirements.txt
streamlit run app.py

## Included
HOME, GST RATE FINDER, GST CALCULATOR, GST VALUATION, BILL PREVIEW, RATE REGISTER, HISTORY and INFO; registration/sign-in/guest access; SQLite storage; Decimal calculations; TXT/PDF/DOCX preview downloads.

## Data and legal limitations
The initial rate register contains only selected milk entries. It is not a complete GST tariff. Check each item against current official notifications, tariff descriptions, conditions and amendments. Manual entries are marked unverified. Valuation workflows are fact-review aids, not legal determinations. Rule 29 is principal-agent goods; Rule 33 is pure-agent expenditure.

## Security limitations
This local starter is not production-grade multi-tenant software. Before public deployment, implement security review, tenant isolation, managed secrets, encryption at rest, MFA, audit logging, backups and deletion controls. Do not enter Aadhaar, PAN, bank credentials or identifiable taxpayer records.

## Disclaimer
GST FINDER IS AN EDUCATIONAL TOOL, NOT AN OFFICIAL GOVERNMENT PLATFORM OR SUBSTITUTE FOR PROFESSIONAL TAX ADVICE. VERIFY ALL GST RATES, CLASSIFICATIONS AND VALUATION METHODS AGAINST CURRENT OFFICIAL NOTIFICATIONS BEFORE MAKING TAX OR BUSINESS DECISIONS.
